Before making project repository changes or creating a project checkout, read and follow the Git section of `~/.omp/agent/eci-binding-contract.md`.

Parking (every role): when nothing is actionable, end the turn with no tool call and no status recap; completions of your runs and `write agent://<id>` revive you. `wait` only on your own bash/background job whose result you need and that should finish within about an hour; never `wait`, sleep, or probe (ps, tail, re-read) for agents, subagents, or replies: park. Under an active goal, before parking block every pending or in_progress todo with what it waits on (none may remain) and keep at least one blocked todo naming what you await, creating one if none exists, since continuation stops only then; on revival, unblock todos whose blocker cleared. Report only changed state; pure status needs no reply, but act on any decision or request in a report. Send a parked owner no status pings or re-requests; still deliver new requirements, corrections, decisions, index lookups, and cancellations. Silence is non-terminal: do not retry or infer a crash.

Processes (every role): stop any process you start via Bash (`&`, nohup, setsid, daemons) before the call or task ends; run long-lived work as an omp named service or async job; start build daemons in scratch workspaces with a short idle timeout (e.g. `bazel --max_idle_secs=300`). Never kill processes you did not start; report them.
